# 단계 D 백엔드 핸드오프 — 이슈 #13

사이클: Critical(동기 추론 시간·민감 입력·오류 경계). 기준 계약: `docs/api.md`의 「D단계 선택적 LIME 확장 계약」과 `docs/lime-measurement.md`.

## 책임

1. TF-IDF 분석 요청의 `includeExplanation` 선택 필드와 응답을 계약대로 구현한다. 기본 분석 경로는 기존 지연 시간과 응답을 유지한다.
2. 기존 `src/explainability/lime_explainer.py`를 재사용한다. 모델·아티팩트 검증 경계를 우회하지 않는다.
3. 설명 실패를 감성 예측 실패와 분리한다. 설명 토큰·LIME 입력 전문·예외 전문이 DB, 운영 로그, 오류 추적, 조회 응답에 남지 않는지 검증한다.
4. 실제 300샘플 지연 시간과 동시성, 요청 제한, 실패 경로를 테스트한다. 강제 중단 가능한 하드 타임아웃이 준비되지 않으면 공개 배포 가능이라고 표시하지 않는다.
5. 기존 Streamlit 파일·모델 가중치·학습 지표는 수정하지 않는다.

완료 기준: `pytest` 전체 및 PostgreSQL 통합 테스트 통과, 보안·코드 리뷰, A에 파일·테스트·남은 운영 제한 보고. 커밋·push·PR 금지.
