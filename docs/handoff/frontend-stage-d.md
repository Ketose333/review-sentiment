# 단계 D 프론트엔드 핸드오프 — 이슈 #13

기준 계약: `docs/api.md`의 「D단계 선택적 LIME 확장 계약」. 백엔드 응답이 준비된 뒤에 진행한다.

## 책임

1. TF-IDF 모델이 `explanationAvailable=true`일 때만 설명 요청 선택 UI를 보인다. 기본값은 선택 해제다.
2. `explanation.status=SUCCEEDED`일 때 긍정·부정 방향을 분명히 표시하고 최대 8개 단어 기여도를 읽기 쉽게 보여 준다. 설명만 실패하면 감성 예측 결과는 유지하고 설명 실패를 별도로 안내한다.
3. 입력 변경 시 과거 분석·설명을 지우고 요청 중 편집을 막는다. 설명 토큰과 리뷰 원문을 URL, 브라우저 저장소, 콘솔, 오류 추적에 남기지 않는다.
4. 실제 FastAPI 연결로 성공·미지원 모델·설명 실패·모바일 화면을 검증한다. 기존 Streamlit 링크는 유지한다.

완료 기준: `npm run lint`·`npm run build` 통과, 실제 API 브라우저 검증, A에 파일·테스트·스크린샷 보고. 커밋·push·PR 금지.
