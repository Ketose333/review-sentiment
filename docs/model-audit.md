# 모델 재학습·출처 점검 (2026-09-23)

## 확인한 사실

| 모델 | 저장 지표 (Accuracy / F1) | 평가 범위 | 판단 |
| --- | --- | --- | --- |
| TF-IDF + LogisticRegression | 0.8370 / 0.8362 | NSMC 테스트 분할 전체 | API 분리에 재학습 불필요 |
| LSTM | 0.8238 / 0.8135 | NSMC 테스트 분할 전체 | 기존 PRD 목표 Accuracy 0.85 미달. 시드 고정 재평가와 학습 기록 확인 필요 |
| KLUE-BERT | 0.8780 / 0.8811 | 테스트 분할에서 `random_state=42`로 뽑은 5천 건 | 기존 PRD 목표 Accuracy 0.88에 소폭 미달. 전체 테스트 분할 재평가 후 재학습 여부 결정 |

수치는 현재 `models/*/metrics.json`의 기록이다. TF-IDF·LSTM과 KLUE-BERT는 평가 표본이 달라 엄밀한 모델 순위나 성능 차이를 주장할 수 없다. KLUE-BERT 학습은 train 1만 8천 건·2 epoch이며 표본 추출 시드는 고정되어 있지만 PyTorch 학습 시드는 코드에서 고정하지 않았다. LSTM 코드는 시드 42를 설정하지만 저장된 가중치의 정확한 학습 실행 메타데이터는 없다. 세 모델 모두 아티팩트와 지표를 연결하는 실행 ID·데이터 revision 기록이 없어 지표 재현까지 확인된 상태는 아니다.

현재 로컬 가중치 네 파일의 SHA-256은 [배포 자산 저장소](https://huggingface.co/datasets/Ketose333/review-sentiment-assets)의 해당 파일 LFS SHA-256과 각각 일치했다. 확인 당시 자산 저장소 revision은 `915d7784e3c81333d6812913b0a80eda37fdbd41`이다. 이는 로컬·배포 파일의 동일성만 입증한다.

기존 테스트는 11개 모두 통과했고, 로컬 가중치로 세 모델을 각각 별도 프로세스에서 로드해 동일한 짧은 한국어 입력의 단건 예측을 확인했다. 이는 로드·추론 경로 확인이며 저장된 Accuracy/F1 재현 검증은 아니다. 점검 환경은 로컬 Python 3.10이므로 배포 대상 Python 3.11 통합 검증도 별도로 필요하다.

## 재학습 결정

API·PostgreSQL·Next.js 분리 자체에는 **재학습이 필요하지 않다**. 새 API는 기존 세 아티팩트를 그대로 사용한다. 단, 모델 비교 화면에서 우열을 주장하기 전에는 동일한 고정 NSMC 테스트 집합으로 세 모델을 재평가하고 모델 파일 해시·데이터 revision·라이브러리 버전·평가 스크립트를 함께 기록한다.

API 입력 상한 500자는 원본 NSMC의 140자 미만 리뷰 범위보다 넓다. LSTM·KLUE-BERT의 내부 토큰 제한도 별도로 작동하므로 긴 입력의 잘림 비율과 지연 시간을 측정한다. 이 사실만으로 즉시 재학습이 필요하다고 결론 내리지는 않는다.

LSTM 목표 0.85와 KLUE-BERT 목표 0.88을 완료 기준으로 계속 사용할 경우에는 현재 결과가 미달이므로 재학습 또는 기준 변경이 필요하다. 전체 데이터/GPU KLUE-BERT 학습은 확장 마일스톤의 필수 조건이 아니다. 공통 평가 결과와 실제 시연 요구를 본 뒤 별도 개선 작업으로 결정한다.

## 출처와 인용

- **NSMC**: 학습 데이터는 [Lucy Park의 원본 저장소](https://github.com/e9t/nsmc)의 `ratings_train.txt`·`ratings_test.txt`에서 받는다. 원본 README는 네이버 영화 리뷰, 평점 1~4의 부정·9~10의 긍정, 5~8 제외, 15만/5만 분할을 설명한다. 레이블은 독립적인 리뷰 감성 수작업 주석이 아니라 **평점에서 유도**되었다. [Hugging Face의 e9t/nsmc 카드](https://huggingface.co/datasets/e9t/nsmc)는 Lucy Park(2016) 인용 형식을 제시한다.
- **NSMC 라이선스 표기**: 원본 GitHub README의 라이선스 절에는 본문이 없다. 같은 이름의 [Hugging Face 데이터셋](https://huggingface.co/datasets/e9t/nsmc)은 메타데이터에 `cc-by-2.0`을 표시하지만 상세 라이선스 절은 비어 있다. 기존 README의 `CC0 1.0` 단정은 원본 근거로 확인되지 않아 삭제했다. 데이터 재배포 조건은 원제공자에게 확인할 때까지 확정하지 않는다.
- **KLUE-BERT**: 베이스 가중치는 [`klue/bert-base` 모델 카드](https://huggingface.co/klue/bert-base)에 표시된 CC-BY-SA-4.0 모델이다. 모델 카드가 제시하는 인용은 [Park et al., *KLUE: Korean Language Understanding Evaluation* (2021)](https://arxiv.org/abs/2105.09680)이다. 이 프로젝트의 자산 저장소도 파인튜닝 출처와 CC-BY-SA-4.0을 표시한다. 프로젝트의 성능 수치는 KLUE 논문의 원모델 평가 수치가 아니라 이 프로젝트의 NSMC 실험 기록이다.
- **TF-IDF·LSTM**: 프로젝트 학습 코드가 NSMC로 학습한 모델이다. 제3자 사전학습 가중치를 사용하지 않는다. 출처는 NSMC와 학습 코드로 표시한다.

모델 해시와 출처 표기는 확인했지만, 과거 학습 실행 로그가 없어 현재 가중치와 공개 지표의 재현 가능성은 아직 검증되지 않았다.

## 동일 표본 재평가 (2026-09-24)

기존 저장 가중치를 변경하지 않고 NSMC 테스트 분할에서 동일하게 추출한 5,000건(`random_state=42`)으로 세 모델을 다시 평가했다. 데이터 revision·원본 SHA-256·표본 SHA-256·모델별 아티팩트 SHA-256·실행 환경·평가 코드는 [재평가 보고서](../reports/README.md)와 [기계 판독 결과](../reports/common_nsmc_5000.json)에 기록했다. 리뷰 원문과 개별 예측값은 보고서에 저장하지 않았다.

| 모델 | Accuracy | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: |
| TF-IDF + LogisticRegression | 0.8282 | 0.8288 | 0.8245 | 0.8266 |
| LSTM | 0.8082 | 0.8512 | 0.7440 | 0.7940 |
| KLUE-BERT | 0.8780 | 0.8539 | 0.9102 | 0.8811 |

이 결과는 저장된 가중치의 **단일 공통 표본 성능**을 확인한다. 기존 TF-IDF·LSTM의 전체 테스트 지표와 이번 표본 지표의 차이를 성능 변화로 해석하지 않는다. KLUE-BERT의 이번 수치는 기존 5천 건 기록과 일치한다. API·웹 분리에는 재학습이 필요하지 않다. Accuracy 0.85(LSTM)·0.88(KLUE-BERT)을 완료 기준으로 유지할지 결정하려면 목표의 평가 집합을 먼저 고정해야 한다. 학습 재현성, 통계적 우열, 다른 도메인의 성능은 이번 평가로 입증되지 않았다.
