# Streamlit 이관 완료 기준

2026-09-24 합의: 새 웹·API가 기존 Streamlit 데모를 대체하려면 사용자에게 제공하는 분석 기능을 유지한다. 로컬 구현과 공개 기능 검증은 통과했지만 장기 안정성 검증 전이라 이관 완료는 아니다. 현재 동작하는 API 계약은 [api.md](api.md)에 기록한다. 정식 공개 주소는 [웹](https://review-sentiment-web.vercel.app), [API](https://ketose333--review-sentiment-api-api.ap-south.modal.run)이다. Vercel은 이 웹 도메인만 연결한다.

## 제공·운영 조건

- API는 `app.py`를 import하지 않고 기존 `src/models`와 전처리·LIME 코드를 재사용한다. 학습·재평가는 이관의 선행 조건이 아니다.
- 세 모델의 가중치 파일은 고정된 Hugging Face revision에서 배포 전에 설치한다. LSTM 토크나이저와 KLUE-BERT 설정·토크나이저 파일은 Git의 `models/`에서 배포한다. 각 필수 파일의 SHA-256을 검증하고, 없거나 검증에 실패하면 해당 모델을 사용 불가로 표시한다. 모델 바이너리는 PostgreSQL에 저장하지 않는다.
- 모델별 지연 로드와 워커 격리를 유지한다. 모델마다 필요한 TensorFlow·PyTorch·Transformers와 JVM의 메모리·시작 시간·동시 실행 수를 실제 후보 호스팅 환경에서 측정한 뒤 인스턴스와 워커 수를 확정한다. 무료 호스팅으로 세 모델을 제공할 수 있다고 가정하지 않는다.
- KLUE-BERT LIME은 Windows 로컬 CPU에서 30샘플에 약 62초가 걸렸다([측정 기록](lime-measurement.md)). 설명 기한을 모델별로 분리했고 Linux 컨테이너 짧은 입력 1회에서 7.78초로 성공했다. 긴 입력·부하 상황과 공개 프록시 기한을 추가 검증한다. 원문과 설명 단어를 DB·로그에 저장하지 않는 조건을 유지한다.
- 실제 주소에서 세 모델 각각의 예측과 설명 성공·실패, 500자 경계, 콜드 스타트, 메모리, 동시 요청, 재시작 후 동작을 확인한다. 모델이 상시 사용 가능한지와 운영 비용을 확인하기 전에는 Streamlit 종료를 결정하지 않는다.
- 공개 배포는 Vercel Hobby + Modal Starter + Neon Free다. Modal 컴퓨트는 유휴 시 0으로 내려가며 첫 요청에 콜드 스타트가 있다. Modal 무료 크레딧 잔액은 2026-09-25 확인 당시 $0.97/$1.00이었고 결제 수단은 등록하지 않았다. 무료 크레딧이나 서비스별 무료 한도 소진 시 요청이 중단될 수 있다.

## 전환 게이트

1. API·웹·DB의 로컬 테스트와 실제 모델 파일을 이용한 세 모델 통합 검증이 통과한다.
2. 공개 배포 환경에서 위 사용자 기능을 세 모델 모두 검증하고, 설명 지연·실패 처리와 운영 비용을 기록한다. 예측·설명 성공, 공개 화면, 입력 경계는 확인했으며 실패 처리·부하·장기 무료 한도는 추가 검증 중이다.
3. 새 주소의 안정성을 확인한 뒤에만 기존 Streamlit 앱과 keep-alive를 이전하거나 종료한다.

중간 단계 배포는 가능하지만 **이관 완료**로 표시하지 않는다.

이관 완료 후에는 실제 구현·테스트·공개 배포 근거를 기준으로 이력서에서 보강하려던 기술 스택의 공백을 다시 평가한다. 사용하지 않은 기술을 이력서에 기재하기 위해 추가하지 않고, 확인된 부족 항목만 후속 작업으로 정한다.
